# Zengo

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

公開URL：https://youngestday.github.io/ba-camera/

## できること

- ビフォーはその場で撮影、または写真ライブラリから選択
- 右側のカメラ映像にビフォーを半透明で重ねて構図を合わせられる（濃さを調整可能、オン・オフ切替）
- 0.5x（超広角）／1x のレンズ切替（対応端末のみ）
- 自動シャッター：ビフォーとの構図の一致度（%）が設定した値を超えると、自動でアフターを撮影
  （一致度は画面右上に表示。しきい値は50〜99%で調整）
- 構図合わせガイド：ビフォーに合わせるための動かし方を矢印で表示
  （上へ／下へ、左へ／右へ、前へ／後ろへ、左右に傾ける角度）
- 重ねたビフォーの色フィルターを 赤／青／緑／黒／なし から選べる
- 1枚ごとの比率は縦長の 9:16（標準カメラの16:9と同じ）
- 「BEFORE / AFTER」の文字を入れるか選べる
- 「保存・共有」から写真アプリに保存

## 使い方

1. iPhoneのSafariかChromeで上のURLを開き、カメラの使用を「許可」する
2. 左側でビフォーを撮る（または「ビフォーを写真から選ぶ」）
3. 右側のカメラで、重なったビフォーに合わせてアフターを撮る
4. 完成画面で「文字を入れる」を選び、「保存・共有」で保存する

ホーム画面に追加すると、アプリのように起動できます。

カメラを使うため https で開く必要があります（GitHub Pages で公開しています）。
