# Zengo

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

公開URL：https://youngestday.github.io/zengo/

## できること

- ビフォーはその場で撮影、または写真ライブラリから選択
- 右側のカメラ映像にビフォーの輪郭を線で重ねて構図を合わせられる（濃さを調整可能。線の色を「なし」にすると重ねない）
- レンズ切替：0.5x（超広角、対応端末のみ）／1x
- インカメ（前面カメラ）にも対応。鏡のように左右反転して表示・保存する
- 一致度：次の2つの平均を出し、画面全体の似かたと低いほうを使う
  - ビフォーの「長くまっすぐな線」（壁と天井・床の境目、窓枠など動かないもの）のずれ
  - 場所ごとのずれ：画面を 上・中・下 × 左・右 の6つに分け、それぞれビフォーと何ピクセルずれているかを輪郭の向きの重なりから探す。いちばんずれている行（上・中・下）で点数を決めるので、上半分だけ合って手前（下のほう）がずれているときはピタッにならない。片付けでなくなった物はどうずらしても重ならないので判定に使わない。手前（下の行）は設定でOFFにできる
- 自動撮影：ビフォーとの構図の一致度（%）が設定した値を超えると、カウントダウン（時計回りに減る円のゲージ。0.3秒固定）のあとアフターを撮影。位置・画角合わせが主役なので、水平・垂直はよほど傾いていなければ（左右5度・前後7度まで）撮る
  （一致度は画面右上に表示。しきい値は50〜90%を5%刻みで調整）
- 構図合わせガイド（ガイドON/OFFで切替、アフター画面はOFFから始まる）：ビフォーに合わせるための動かし方を ↑↓←→ の矢印だけで表示（文字は出さない。線画を合わせることに集中できるように）。ずれが大きいほど矢印も大きい。「↓」は画面のいちばん下に出し、傾きのスマホ形の枠と重ならない
- ピタッ：一致度が設定値を超えると、緑の枠と「ピタッ！」の表示、音で知らせる。自動撮影ONなら、ピタッが出たら必ず撮る（ピタッと自動撮影は同じ条件。一度合ったら一致度が5%下がるまで合ったままにして、手ブレで数字が揺れてもカウントダウンが途切れないようにしている。アフター画面に入って1.5秒はピタッも出さない。ビフォーをまっすぐ撮っていて、アフターが大きく傾いているときもピタッは出ない）
- シャッター音（「カシャ」）
- 3×3のグリッド（アフターを撮るときは、左のビフォー写真にも同じグリッドを出して見比べられる。保存画像には入らない）と水平・垂直ガイド（左右の傾きで回る線は水平で黄色の1本に。まん中のスマホ形の枠は前後の傾きで台形になり、まっすぐ立つと黄色の長方形に）
- ビフォーの自動撮影：自動撮影ONのとき、水平・垂直がそろうとカウントダウン（設定で0.5〜2秒、初期値1秒）のあとビフォーを撮影
- 設定画面（左上の「設定」）：ピタッの音・シャッター音・グリッド・手前（画面の下のほう）も合わせる・水平・垂直ガイドのON/OFF、ビフォーの自動撮影までの時間
- 撮影中はビフォーから壁・窓・家具の縁などの輪郭だけを取り出し、線にしてカメラ映像に重ねる（線の色は 赤／青／緑、「線なし」で重ねない。濃さも調整可）
- 重なりチェック：完成画面の写真のすぐ下のスライダーのつまみを左へ滑らせると、ビフォーが右へ・アフターが左へ寄って重なり、ずれを確かめられる（指を離すと戻る）。ビフォーは線画になって、アフター写真の上に重なる
- 1枚ごとの比率は 16:9／4:3／1:1 から選べる（どれも縦長。撮った後の完成画面でも変更可）
- 「BEFORE / AFTER」の文字を入れるか選べる
- 「保存・共有」から写真アプリに保存

## 使い方

1. iPhoneのSafariかChromeで上のURLを開き、カメラの使用を「許可」する
2. 左側でビフォーを撮る（または「ビフォーを写真から選ぶ」）
3. 右側のカメラで、重なったビフォーに合わせてアフターを撮る
4. 完成画面で「文字を入れる」を選び、「保存・共有」で保存する

ホーム画面に追加すると、アプリのように起動できます。

カメラを使うため https で開く必要があります（GitHub Pages で公開しています）。
