# Zengo

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

公開URL：https://youngestday.github.io/zengo/

## できること

- ビフォーはその場で撮影、または写真ライブラリから選択
- 右側のカメラ映像にビフォーを半透明で重ねて構図を合わせられる（濃さを調整可能、オン・オフ切替）
- レンズ切替：0.5x（超広角、対応端末のみ）／1x／2x（1xの中央を2倍に切り出し）
- インカメ（前面カメラ）にも対応。鏡のように左右反転して表示・保存する
- 自動撮影：ビフォーとの構図の一致度（%）が設定した値を超えると、カウントダウン（時計回りに減る円のゲージ。設定で0.3〜1.5秒、初期値1秒）のあとアフターを撮影
  （一致度は画面右上に表示。しきい値は50〜90%を5%刻みで調整）
- 構図合わせガイド（ガイドON/OFFで切替、アフター画面はOFFから始まる）：ビフォーに合わせるための動かし方を矢印で表示
  （上へ／下へ、左へ／右へ、前へ／後ろへ、左右に傾ける角度）
- ピタッ：一致度が設定値を超えると、緑の枠と「ピタッ！」の表示、音で知らせる
- 傾きセンサー：ビフォーを撮ったときのスマホの傾き（上下・回転）と比べて表示。自動シャッターは傾きも合ったときだけ撮る
- シャッター音（「カシャ」）
- 3×3のグリッドと水平・垂直ガイド（左右の傾きで回る線は水平で黄色の1本に、前後の傾きで上下に動く丸はスマホがまっすぐ立つと黄色に）
- 設定画面（左上の「設定」）：ピタッの音・シャッター音・グリッド・水平線・傾きセンサーのON/OFF、自動撮影までの時間
- 重ね方を「線」と「写真」から選べる
  - 線：ビフォーから壁・窓・家具の縁などの輪郭だけを取り出し、線にして重ねる（短い線は省いてシンプルに）
  - 写真：ビフォー写真を薄く重ねる
- 重ねる色を 赤／青／緑／なし から選べる（写真のときは濃さ40%のフィルター、線のときは線の色）
- 1枚ごとの比率は 16:9／4:3／1:1 から選べる（どれも縦長。撮った後の完成画面でも変更可）
- 「BEFORE / AFTER」の文字を入れるか選べる
- 「保存・共有」から写真アプリに保存

## 使い方

1. iPhoneのSafariかChromeで上のURLを開き、カメラの使用を「許可」する
2. 左側でビフォーを撮る（または「ビフォーを写真から選ぶ」）
3. 右側のカメラで、重なったビフォーに合わせてアフターを撮る
4. 完成画面で「文字を入れる」を選び、「保存・共有」で保存する

ホーム画面に追加すると、アプリのように起動できます。

カメラを使うため https で開く必要があります（GitHub Pages で公開しています）。
